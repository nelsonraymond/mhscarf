# MH Scarf — Demo Image Sources & License Notes

> **Purpose:** development / academic demonstration only. The storefront needs
> imagery for products that have no uploaded photography yet. Every demo image
> is downloaded into **local storage** (`storage/app/public/products/`) — the
> site never hotlinks to external URLs.

## Important disclaimer

The stock photographs listed below are **illustrative model/lifestyle imagery**.
They are **NOT verified photographs of the actual MH Scarf merchandise** (fabric,
color, and drape may differ). Replace them with real catalog photography before
any production launch. Alt texts generated by the seeders always end with
`(demo image)` so placeholder content is identifiable in the markup.

Pexels photo id**. Seeders (`ProductImageSeeder.php`, `fetch-demo-images.php`)

reported as pending** — it is never filled with unrelated imagery.

## License / attribution

- **Pexels License** (https://www.pexels.com/license/): free to use, modify,
  and redistribute, even commercially; attribution not required but
  appreciated. Photographer names should be checked on each photo page when
  finalizing credits.
- Images previously seeded from **Lorem Picsum** (generic photos, now replaced
  in the tooling) can be removed cleanly:
  ```sql
  DELETE FROM product_images WHERE image_path LIKE 'products/demo-%';
  ```
  then delete matching files in `storage/app/public/products/` and re-run the
  seeder. Admin-uploaded images are never touched by these tools.

## How to populate

```bash
php artisan db:seed --class=ProductImageSeeder   # Laravel path (recommended)
# or, without composer/Laravel bootstrap:
php database/seeders/fetch-demo-images.php 127.0.0.1 3306 MH Scarf_store root ""
php artisan storage:link                          # if not already linked
```

Both tools skip products that already have image records and are safe to
re-run.
